# Birthday Surprise Website ❤️

## Files
- index.html — main website
- style.css — design and animations
- script.js — countdown and effects

## Customize
1. In `index.html`, replace "My Future Wife" and the message with your own words.
2. Replace the sample photo boxes with your photos if desired.
3. Upload all files to a GitHub repository.
4. Enable GitHub Pages from Settings → Pages → Deploy from branch → main → / (root).

No server or database is required.
